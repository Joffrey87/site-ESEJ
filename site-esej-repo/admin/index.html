Chargement…
Comment ça marche ?
  1. Ouvrez une page ou un réglage, modifiez, puis cliquez sur Publier (en haut à droite de l’éditeur).
  2. Le site se met à jour automatiquement en 1 à 2 minutes. Rechargez la page du site pour voir le résultat.
  3. Pour retirer une page du menu sans la supprimer, décochez « Afficher dans le menu » dans ses réglages.
