Mode édition du site de l’École du Saint-Enfant-Jésus

Comment ça marche ?

Modifier une page

  1. Cliquez sur une page (ou « Modifier »). L’éditeur s’ouvre : le formulaire à gauche, l’aperçu de la page à droite.
  2. Cliquez directement sur un texte dans l’aperçu pour le modifier : la saisie est reportée dans le formulaire. Les photos, l’ordre des sections et les réglages se changent dans le formulaire.
  3. Cliquez sur Publier (en haut). Le site se met à jour en 1 à 2 minutes ; rechargez la page du site (Ctrl+F5) pour voir le résultat.
  4. La flèche « ← » ou « Tableau de bord » ramène ici. Si vous quittez sans publier, il vous sera demandé de confirmer.

Pages

  • « + Nouvelle page » : le nom donne l’adresse (« Nos activités » → nos-activites.html). Ajoutez ensuite des sections (introduction, texte + image, liste…).
  • Pour retirer une page du menu sans la supprimer : dans « Réglages de la page », décochez « Dans le menu du haut ».
  • Pour supprimer une page : l’ouvrir → « Supprimer l’entrée ».

Comptes

  • Toute personne peut créer un compte depuis l’écran de connexion ; il reste inactif jusqu’à validation par le Grand Administrateur (Menu administrateur → Comptes).
  • Le Grand Administrateur peut transmettre son rôle (« Définir Grand Administrateur ») ; il n’y en a qu’un à la fois.

Historique

Le Menu administrateur liste chaque publication : date, auteur, page concernée. Rien n’est jamais perdu : chaque version est conservée.
