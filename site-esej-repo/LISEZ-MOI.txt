========================================================
  SITE DE L'ÉCOLE DU SAINT-ENFANT-JÉSUS — MODE D'EMPLOI
========================================================

Le site est généré automatiquement à partir du contenu saisi dans
l'interface d'administration. Vous n'avez jamais besoin de toucher au code.

--------------------------------------------------------
1) MODIFIER LE SITE (interface d'administration)
--------------------------------------------------------
Adresse : https://saint-enfant-jesus2.netlify.app/admin/
Accès discrets depuis le site :
  - le petit cadenas à la fin de la ligne « © … » en bas de page ;
  - l'icône crayon qui apparaît au survol du coin haut-droit de la page.
Connexion : e-mail + mot de passe. Le tableau de bord présente les pages en
vignettes, les réglages, la médiathèque et (pour le compte Maître) les comptes.

COMPTES ET RÔLES
  - « Créer un nouveau compte administrateur » (écran de connexion) : chacun
    choisit son nom, son e-mail et son mot de passe. Le compte est créé « en
    attente » : il ne peut rien modifier tant que le trésorier ne l'a pas validé.
  - Le compte Maître (trésorier) reçoit un e-mail à chaque inscription et
    valide / refuse / suspend les comptes dans la rubrique « Comptes » du
    tableau de bord.
  - CHANGEMENT DE TRÉSORIER : le Maître en poste ouvre « Comptes », puis clique
    « Lui confier le rôle Maître » sur la ligne du nouveau trésorier (son compte
    doit déjà exister et être validé). Le nouveau devient Maître, l'ancien
    redevient simple administrateur. Il n'y a qu'un seul compte Maître à la fois.
    En dernier recours (Maître perdu ou inaccessible), un responsable du compte
    Netlify peut réattribuer le rôle : Netlify → Identity → cliquer sur
    l'utilisateur → Edit settings → Roles = maitre (en minuscules).
  - Rôles Netlify : maitre (trésorier), admin (peut tout modifier),
    en_attente (aucun droit). Réglages Netlify à conserver : Identity →
    Registration = Open ; Services → Git Gateway → Roles = admin, maitre ;
    variable d'environnement WEB3FORMS_TRESORIER_KEY = clé Web3Forms créée
    avec l'adresse e-mail du trésorier (pour la notification).

Dans l'éditeur :
  - « Réglages généraux » → Réglages du site : coordonnées, réseaux sociaux,
    pied de page, don HelloAsso, formulaire de contact, bloc « Aidez-nous », carte.
  - « Réglages généraux » → Page d'accueil : tous les textes et photos de l'accueil.
  - « Pages » : chaque page du site. Bouton « Nouvelle page » pour en créer une
    (choisir son adresse, son nom dans le menu, sa position, puis ajouter des blocs).
    Pour supprimer une page : ouvrir la page → menu « … » → Supprimer.
  - Les images se choisissent / se téléversent avec le bouton « Choisir une image ».

Après « Publier », le site se met à jour tout seul en 1 à 2 minutes
(rafraîchir la page avec Ctrl+F5 si nécessaire).

--------------------------------------------------------
2) TYPES DE BLOCS DISPONIBLES (pages standard)
--------------------------------------------------------
  - Introduction sur photo de fond (grand titre + texte dans un cadre blanc)
  - Texte + image (image à gauche ou à droite, fond clair ou doré)
  - Texte seul
  - Deux colonnes de texte
  - Liste numérotée avec images (questions/réponses, moyens d'aider…)
  - Texte long (mentions légales, règlement…)
Le bloc « Aidez-nous » se règle une fois pour toutes dans Réglages du site
et s'affiche en bas des pages où l'option est cochée.

--------------------------------------------------------
3) FONCTIONNEMENT TECHNIQUE (pour info)
--------------------------------------------------------
  - content/          : le contenu (fichiers JSON modifiés par l'admin)
  - templates/        : les gabarits HTML (enveloppe + blocs) — ne pas modifier
  - assets/theme.css, assets/blocks.css : le style du site (Divi consolidé)
  - build.js          : génère le site dans dist/ (exécuté par Netlify)
  - admin/            : l'interface d'administration (Decap CMS)
  - wp-content/uploads/ : les images (mediatheque/ = médiathèque de l'admin)
  - netlify/functions/ : inscription (identity-signup) et gestion des comptes (comptes)
Hébergement : Netlify (déploiement automatique à chaque modification GitHub).
